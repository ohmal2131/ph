# Flowly ランディングページ

架空のチーム向けワークスペースSaaS「Flowly」のランディングページです。
ビルド不要の静的サイト（HTML / CSS / JavaScript）で構成されています。

## 構成

```
.
├── index.html     # ページ本体
├── css/style.css  # スタイル
└── js/main.js     # インタラクション
```

## セクション

1. ヒーロー（キャッチコピー・CTA・プロダクトモック）
2. 導入企業ロゴ
3. お悩み提起
4. 特長（3つの理由）
5. 使い方（3ステップ）
6. 実績数値（カウントアップ）
7. 導入事例
8. 料金プラン（月払い／年払い切り替え）
9. よくある質問（アコーディオン）
10. 最終CTA（メール登録フォーム）

## 主な機能

- レスポンシブ対応（モバイルはハンバーガーメニュー＋追従CTA）
- スクロール連動のフェードインアニメーション
- `prefers-reduced-motion` 対応
- キーボード操作・スクリーンリーダーへの配慮

## ローカルで確認

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## カスタマイズ

- 配色は `css/style.css` 冒頭の CSS 変数（`--c-primary` など）で変更できます。
- テキスト・料金・FAQ は `index.html` を直接編集してください。
- 登録フォームはデモ動作です。`js/main.js` の `TODO` 箇所で実際のAPIに接続してください。

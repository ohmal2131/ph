# KIMONOsalon 成人式 振袖レンタル展示会 LP

ビューティサロンモリワキ「KIMONOsalon」の、成人式 振袖レンタル展示会のご予約用ランディングページです。
`index.html` 1ファイルだけで動きます（ビルド不要）。ダブルクリックするとブラウザで開けます。

- ターゲット：来年成人式を迎える新成人と、そのご両親
- コーポレートカラー：明るめのグリーン（`index.html` 冒頭の `--green` で変更できます）

## ページ構成

1. メインビジュアル（キャッチコピー・開催概要・予約ボタン）
2. メッセージ
3. 選ばれる理由（3つ）
4. 振袖コレクション（写真枠）
5. 新成人の方へ／ご家族の方へ（タブ切り替え）
6. 展示会 開催概要・開催日程
7. ご成約特典
8. レンタルプラン
9. 成人式当日までの流れ
10. よくあるご質問
11. ご予約フォーム＋電話番号
12. アクセス

スマホでは、画面下に「電話する」「展示会を予約する」ボタンが追従します。

## 差し替えが必要な箇所（「○」の部分）

- 成人式の年（令和○年）
- 展示会の日程・時間・最終受付・各時間帯の予約枠数
- 会場（店舗）の住所・電話番号・営業時間・定休日・駐車場
- ご成約特典の内容
- レンタルプランの料金・セット内容・オプション
- FAQ の所要時間
- 振袖の写真（コレクション欄）・Google マップ
- 個人情報の取り扱い（プライバシーポリシー）ページへのリンク

## 予約フォームについて

入力チェックと完了表示まではできていますが、**送信先にはまだつながっていません**。
`index.html` 内の `TODO` 箇所で、メール送信サービスや予約システム、Googleフォームなどにつなぐ必要があります。

## 予約フォームを Google フォームにつなぐ手順

1. Google フォームを新規作成し、次の6項目を作ります（質問名は自由です）。
   - お名前（記述式）
   - 電話番号（記述式）
   - 成人式の年（ラジオボタン：`2028年1月`／`2029年1月`／`その他` ※この文字のとおりに）
   - ご希望日（記述式。プルダウンにする場合は LP の選択肢と同じ文字にする）
   - ご希望時間（記述式）
   - ご質問・ご要望（段落）
2. フォーム右上の「︙」→「事前入力したURLを取得」で、各項目に適当な値を入れて「リンクを取得」します。
3. 取得したURLに含まれる `entry.数字` が各項目の ID です。URLの `/viewform` を `/formResponse` に変えたものが送信先です。
4. `index.html` 内の `GOOGLE_FORM` に送信先と各 ID を書き込みます。

```js
const GOOGLE_FORM = {
  action: 'https://docs.google.com/forms/d/e/XXXXXXXX/formResponse',
  entries: { name: 'entry.111', tel: 'entry.222', year: 'entry.333', date: 'entry.444', time: 'entry.555', message: 'entry.666' },
};
```

`action` が空のあいだは、送信しても完了画面を表示するだけのデモ動作です。
回答は Google フォームの「回答」タブやスプレッドシートで確認できます。
